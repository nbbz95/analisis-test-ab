    Cómo se calculó

    • Unidad de análisis: usuario. Se descartan filas con grupo y página que no coinciden y usuarios repetidos (se conserva su primera visita).
    • Sample Ratio Mismatch: chi-cuadrado contra un reparto 50/50.
    • Efecto: test z de dos proporciones, bilateral, α = 0,05. IC de Wald para la diferencia.
    • Potencia: con 80% de potencia, efecto mínimo detectable con la muestra real y muestra necesaria para el mínimo de negocio.
    • Decisión: se lanza solo si el intervalo completo queda por encima de cero; si el intervalo descarta la mejora buscada, se mantiene la página actual.
